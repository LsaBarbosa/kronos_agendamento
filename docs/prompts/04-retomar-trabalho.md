# Prompt — retomar o desenvolvimento

```text
Retome o App Agendamento a partir do estado real deste repositório.

Leia AGENTS.md, docs/development/STATUS.md, TRACEABILITY.md, o plano em
andamento, decisões aplicáveis e OPEN-QUESTIONS.md, quando existirem.
Confira Git, alterações locais e o código relacionado. Compare o estado
documentado com o observado antes de decidir o que falta.

Se os registros estiverem desatualizados, corrija-os com evidências sem
apagar trabalho alheio. Não repita entregas já comprovadas nem assuma que
uma tarefa está pronta apenas porque o status diz isso.

Continue o próximo passo do incremento que já estava autorizado, usando
as skills pertinentes e subagentes somente em frentes independentes úteis.
Se esse incremento já terminou, selecione a próxima história P0 com
dependências atendidas e implemente-a conforme o prompt de implementação.

Resolva decisões técnicas reversíveis dentro da arquitetura. Para uma
decisão de produto indispensável ainda não tomada, exponha a questão,
recomende uma opção com trade-off e avance nas partes independentes.

Mantenha os planos e a rastreabilidade atualizados. Ao final, reporte
resultado, testes, pendências, benefícios, trade-offs e próximo passo.
```

Para retomar somente uma história específica, substitua a seleção automática por: `Continue exclusivamente AGD-xxx, sem iniciar outra história.`
